# Apex Custom Sculptural Features LLC

A modern, responsive, high-end luxury portfolio website built for a specialty art and hardscaping studio. 

## Features
* **Custom Vanilla JavaScript Lightbox:** Click on any portfolio image or video to view it in full screen without relying on heavy third-party plugins.
* **Portfolio Filtering:** Sort projects dynamically (Statues, Molds, Hardscaping, Video) using smooth CSS transitions.
* **Responsive Design:** Fully fluid layout using CSS Grid and Flexbox, adapting seamlessly from large desktop displays down to mobile devices.
* **Glassmorphism & Luxury Aesthetics:** Deep slate backgrounds, gold accenting, and blurred transparency layers for a premium user experience.
* **Zero Dependencies:** 100% pure HTML5, CSS3, and Vanilla JS.

## Deployment on GitHub Pages
This project is structured specifically to be deployed natively on [GitHub Pages](https://pages.github.com/). 

## How to Customize
1. **Images:** Replace the placeholder `src` attributes in the `<img />` tags within `index.html` with your actual project images.
2. **Video:** Replace the `.mp4` link in the `<video>` tag with a link to your hosted video.
3. **Contact Info:** Scroll to the bottom of `index.html` to update the mailto:, Facebook, and Telegram placeholder links.
